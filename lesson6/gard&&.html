Short-Circuiting with OR (||) Behavior: The || operator evaluates the first operand. If it's truthy, the overall result is immediately determined to be true, and the second operand is not evaluated. Use Case: It's commonly used to provide default values, handle fallback conditions, or execute code only if a condition is false. Examples of Using OR (||) 1. Provide Default Values Use || to assign a default value if a variable is null, undefined, or another falsy value. javascript Copy code const user = null; // Default to "Guest" if user is null or undefined const name = user || "Guest"; console.log(name); // Output: "Guest" 2. Fallback for Function Parameters Provide a default value for function arguments. javascript Copy code function greet(name) { name = name || "stranger"; console.log(`Hello, ${name}!`); } greet("Alice"); // Output: "Hello, Alice!" greet(null); // Output: "Hello, stranger!" ⚠️ Note: In modern JavaScript, you should use the ?? (nullish coalescing) operator if you only want to handle null or undefined. Example: name ?? "stranger". 3. Conditional Execution (Guard) Run a function or block of code only if the first condition is falsy. javascript Copy code const isLoggedIn = false; // Only execute if not logged in !isLoggedIn || console.log("You need to log in."); // Output: "You need to log in." 4. Lazy Evaluation Use || to avoid expensive computations if the first operand is truthy. javascript Copy code const expensiveComputation = () => { console.log("Running computation..."); return 42; }; // Only compute if the first value is falsy const result = true || expensiveComputation(); // Output: (nothing happens since the first operand is true) console.log(result); // Output: true 5. Guard Access to Optional Properties Similar to &&, but ensure a default value if a property doesn’t exist. javascript Copy code const data = { user: { name: "Alice" } }; // If data.user.name is undefined, fallback to "Anonymous" const userName = data.user.name || "Anonymous"; console.log(userName); // Output: "Alice" 6. Set Defaults for Objects Simplify setting default properties for objects. javascript Copy code const config = { theme: null, }; // Use a default theme if no theme is provided const theme = config.theme || "light"; console.log(theme); // Output: "light" Why Use Short-Circuiting for ||? Efficiency: Avoid unnecessary computations when a value is already truthy. Fallbacks: Simplify code for providing defaults or handling missing values. Conciseness: Reduce the need for explicit if statements. A Comparison: AND (&&) vs OR (||) AND (&&): Stops evaluating if the first operand is false.
